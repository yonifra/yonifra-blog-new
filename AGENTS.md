# AGENTS.md

Welcome, AI Agent! This repository is a personal blog built with Gatsby and MDX.

## Project Context
This is a standard Gatsby blog using the Novela theme (or similar). Content is written in MDX and stored in `content/posts/`.

## Tech Stack
- **Framework:** Gatsby
- **Format:** MDX (Markdown for component-era)
- **Styling:** CSS-in-JS (via Gatsby theme)

## Blog Post Structure
Each blog post resides in its own folder under `content/posts/`.
Format: `YYYY-MM-DD-slug/`

Inside the folder:
- `index.mdx`: The main content file.
- `images/`: Directory for the hero image and other assets.

## Guidelines for Agents
1. **Frontmatter:** Every `index.mdx` must have a frontmatter with `title`, `author`, `date`, `hero`, and `excerpt`.
2. **Hero Image:** Always include a high-quality hero image in the `images/` directory.
3. **Drafting:** When writing posts, maintain a professional yet personal tone.
4. **Skills:** Refer to the `.agents/skills/` directory for specific automated workflows.
